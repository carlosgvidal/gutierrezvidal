# Gramática de inferencia LIMES 0.2.0

## Principio general

La interpretación se construye desde proposiciones y relaciones sintácticas. La presencia de una palabra no constituye por sí misma una dimensión semiótica, un actor, un objeto de valor, un programa o una frontera.

## Proposición

Una proposición requiere un predicado reconocido y conserva fuente, destino, complemento, modalidad, negación y localización de evidencia.

## Actante y agencia

Un actante es una frase nominal o pronominal que ocupa un rol funcional en una proposición. La agencia sólo se marca cuando el actante ocupa la fuente de una operación. Actante y actor no se consideran equivalentes ontológicos.

## Ser

Ser se resuelve únicamente mediante predicación copular con fuente identificada y atributo o identidad complementaria.

## Estar

Estar se resuelve mediante predicación relacional o situacional con fuente identificada.

## Decir

Decir se resuelve mediante operación enunciativa con fuente identificada. Las operaciones performativas pueden aportar simultáneamente evidencia de Decir y Hacer.

## Hacer

Hacer se resuelve mediante operación agentiva o performativa con fuente identificada. Una operación orientada a transformación no se confunde con un cambio de estado observado.

## Objeto de valor

Un objeto de valor candidato requiere un complemento sintáctico constituido y una operación cuyo predicado exprese una dirección de objetivo. No se utilizan ventanas de palabras ni temas generales como sustitutos del objeto.

## Programa

Un programa requiere actante fuente, objeto de valor y dirección de objetivo. Un contraprograma requiere direcciones incompatibles de actantes distintos sobre el mismo objeto.

## Relación

Una relación dirigida exige fuente y destino identificables en la misma estructura proposicional. La coocurrencia no constituye relación.

## Frontera

Una frontera sólo se infiere cuando una operación explícita entre dos actantes expresa restricción, permeabilidad o legitimación. No se utilizan umbrales de frecuencia para producir propiedades de frontera.

## Transformación

Una operación con dirección de objetivo puede registrarse como operación transformativa. El cambio de estado permanece sin resolver mientras no exista evidencia temporal suficiente para comparar estados.

## Abstención

Toda estructura que no satisfaga sus condiciones permanece sin resolver o no se genera.
